## Recommendation Summary

工具输出先在本地按实际数据可达性形成允许给当前模型服务的安全诊断，敏感原始日志不进入模型。旧结果只提取安全元数据，新结果固定首次回执的安全投影，以可追溯引用发布；模型先搜元数据，再按需分页读取同一内容。摘要保存任务方向和运行时验证的引用，旧正文不能通过恢复或摘要绕过入口门。

模型请求在消息和工具目录完全确定后统一校验内容许可与容量。历史测试事实只支持当时版本，不能直接替代当前交付验证。模型再调用外部工具时，执行层按具体接收方重新核验内容；默认发送受信任的固定产物引用，拒绝借自由文本参数绕过许可。D7 继续负责未知副作用恢复，用户批准不能使 uncertain 自动变成可重试。

双通道不意味着保存所有私有原始日志。首版默认短暂本地处理，持久化只保留允许内容和恢复所需事实。详细测试诊断要求独立的允许文件工作区、合成输入、固定镜像/依赖、无凭证与禁网络；当前整仓库 Docker 挂载不是这份证明。
