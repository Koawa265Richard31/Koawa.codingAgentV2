## Ordered Work Packages

### WP-A：恢复与压缩基线核验

复现同线程首轮、后续新 turn、失败回合、恢复、连续压缩。F20 验收不能只测“有历史前缀”：需要取证中的空 seed/非空 loop 条件，并验证相同项数但内容不同仍被发现。比较规范化后的上下文身份、顺序与来源映射，而不是原始/脱敏字符串混比。

压缩 intended/compacted 的前置校验、崩溃窗口与重放要分别验证。F21 终态处理只能防止线程卡住，不能证明已有执行流一致。未通过前，可做独立组件，但不能对外启用依赖错误恢复链的检索。

### WP-B：数据契约、入口门与完整请求门

建立本地受信任 ProjectionPolicy，输入包括来源、实际隔离证明、模型接收方、字段释放规则和当前策略版本。unknown 默认正文不可见；受限状态也须有释放契约。外部字符串不能创建 trusted 标签。

入口覆盖普通 tool result、恢复回执、session preload、摘要模型、检索工具、错误与异常输出；最终 provider adapter 再验证请求中每项 provenance，防止漏接入口。工具 schema/描述同样受配置来源和大小约束，但可见不代表有指令权威。

定义最终 request 计量接口，包含真实序列化输入和 provider 已知开销/预留；任何压缩开关与提前返回不影响该检查。先用离线合成请求建立测量正确性，再实测估算误差。验收：所有通往 provider 的实际路径使用门禁，未知模型计量配置不能静默零估算。

### WP-C：安全诊断环境与适配器

为测试建立仅允许代码/依赖/合成输入的独立工作区，核验挂载、镜像、环境和禁网络，保护路径解析与复制时的身份一致性。现有 host runner 和整仓库挂载默认保持受限输出身份。

对 MCP 按服务/工具/schema/绑定建立输出适配器；未知正文不参与摘要、embedding 或搜索预览。详细诊断可包含哪些堆栈与值取决于已证明的输入可见性。真实敏感测试只运行维护者定义的固定释放契约，防止模型借真假查询提取秘密。

验收以合成秘密覆盖 env、文件、镜像、链接、网络和日志编码；不是只断言启动参数含 network none。容器不可用时明确禁用详细路径，不自动切换宿主后继续共享正文。

### WP-D：JSON 投影发布与留存

落实完整设计的发布提交点。拟定领域事件族：result.projection-published.v1、result.projection-unavailable.v1、result.projection-revoked.v1、result.projection-expired.v1；命名可按仓库规范细化，含义不能混为工具成功/失败。正文是不可变 JSON，发布事件记录正文引用和安全元数据；写入使用 expected stream version。

执行终态先有可信记录；投影失败不得重新调用工具。模型首次回执必须来自已发布的同一投影；未发布则返回安全不可用状态，不能临时回显私有文本。幂等发布键绑定 execution_id＋投影契约版本；重试不能写出同身份不同内容。

注入故障：工具已完成/正文未写、正文已写/事件 CAS 冲突、事件已写/索引未更新、撤销已写/清理未完成。验收：无越权可见孤儿、无自动重执行、可辨别正文不可用、清理有状态。

### WP-E：元数据搜索与投影读取

当前线程和工作区作用域从 execution context 取。索引由已发布事件增量重建，正文不可索引时不提取关键词。旧事件仅允许已审核的身份/状态字段；现有脱敏记录不自动获准全文。

游标绑定结果或查询、水位、策略范围和过期，固定排序确保翻页不重复混淆版本。返回包含 complete/truncated/availability，索引水位不足不能冒充全量无结果。配额同时约束响应、总读取、扫描工作量和存储；计数不可通过重复页、新 turn 或恢复重置。

验收：伪造 ref/cursor、权限撤销、换模型接收方、跨线程、索引缺失/损坏均不触发原始事件正文回退。

### WP-F：摘要引用、保护组与成本控制

摘要引用只绑定当前权限内真实记录，保留来源与适用基线；无效引用不能落入可信证据区。历史压缩不遗漏当前约束，不破坏未完成 call/result。长期摘要可滚动合并，已完成旧用户回合不无限豁免，歧义约束保留或明确容量不足。

稳定前缀减少无关变化，近期消息与检索内容靠后追加。不保留越权/陈旧授权内容来提高缓存，不把缓存失效当错误。补压缩后检索、旧摘要再次压缩后搜索、正文过期等测试。

### WP-G：固定产物外发

实现 export_artifact_ref 与 destination_ref 的可信解析，构造固定字节负载再绑定 D9 action。受限数据的模型改写不是可追踪来源证明，默认不能以“模型自己写的报告”为由外发。

检查实际发送的 URL、账户、参数、标题、文件名和内容；凭据只由授权通道注入，未持久化。执行前与实际发送处绑定同一快照；重定向或绑定变化重新判定。盘点现有远程搜索、MCP、网络测试和 shell 旁路，没有纳管的路径在受保护模式关闭。

发送超时保留 D7 uncertain；批准不会重置账本。验收同时覆盖批准后产物变化、跨账户目标、MCP refresh、断线、重复调用与恢复。

### WP-H：真实长任务与上线参数报告

完成下面的实验矩阵后生成参数选择报告，写明候选参数、测量结果、置信限制与最终选值。报告记录配置摘要和代码版本，可供后续复测。安全不变量失败的候选直接淘汰，不用成本收益抵消。

## Compatibility And Migration

旧库不改写历史事件。建立安全派生索引；恢复入口重新投影未知正文为不可用说明，并保持 tool call/result 协议闭合。新事件用版本化 schema 和兼容读取器；旧二进制不能在不识别新可见性门的情况下继续发送模型请求。

新投影正文到期不等于执行证据作废；必要最小事实留存遵从原运行恢复契约。过期索引不能指向被复用的 ID。备份与恢复必须携带撤销水位，不能复活已撤销投影。

## Tactical Protections During Migration

保留 D7 claim/账本、D9 动作摘要/批准、现有工具身份、generation 和文件基线检查。旧敏感正文不可通过“先做一个小功能”开放；检索不可用时明确返回不可用，不降级读取原始日志。F20/F21 修复独立验收，不以新索引绕过。

## Performance And Resource Benchmarks

| 待定参数/决策 | 工作负载与量测 | 选择规则 |
| --- | --- | --- |
| 单页字节/token、搜索候选数 | 短状态、长堆栈、中文、MCP JSON、分割关键诊断 | 保留诊断完整度并限制单次请求开销 |
| 累计页数/读取量/查询工作量 | 重复页、跨 turn、kill/resume、无效搜索循环 | 正常长任务可完成，恶意或无效循环有有限上界 |
| 软/硬窗口、输出预留、摘要触发 | 稳定工具目录与大目录、长用户输入、多模块任务 | 最终不超 provider 限额；任务质量与总成本共同比较 |
| 投影/线程存储与保留期限 | 多轮会话、过期后复查、事件重建 | 满足复查用途，增长与清理可控；正文到期可解释 |
| 摘要合并节奏与缓存 | 同模型同任务比较不同合并策略 | 用 provider 报告的 cached/input tokens 和总费用衡量 |
| 详细诊断契约覆盖 | 可安全复现与必须真实数据的失败 | 分开统计修复成功与诊断不足，不能混成总成功 |

先跑离线可靠性/容量基线，再跑相同任务集合的三种模式：无检索、元数据检索、安全投影检索。记录任务完成率、修复正确性、定位关键原因比例、错误历史证据使用次数、轮数/重试、输入输出与缓存 token、总费用、检索及工具完成 p95、峰值 RSS、磁盘增长、索引重建和清理时间。

测量请求容量、用户可见工具调用次数与 provider 请求轮数时分别命名，不混为“轮”。现有 run10 的 82.3% 缓存命中只是一条既有冒烟记录，不当成本设计的收益基准或承诺。

所有运行模式都需有限配置值，但本设计不拍数字。测试实施时从可验证的 provider 限额与测试资源约束生成候选，再记录参数来源；正式启用前必须有参数报告，不能把示例数值带进默认配置。

## Rollout And Rollback

先离线契约与故障测试，再受限来源灰度，再真实长任务。每一阶段都保留首返模型入口和最终容量检查。可独立关闭详细诊断、检索、外发；关闭正文发布后仅返回安全状态。不能回滚到会重新开放旧敏感正文的旧路径。

投影策略出错时先撤销可见性、再清理，监测模型请求与发送日志的安全元数据。已经对外发送不可撤回，不宣称策略修复能逆转既往披露。

## Acceptance Criteria

完成条件同时满足：全部既定安全矩阵通过；真实首轮/同线程后续 turn/恢复/压缩/交付链可运行；检索到的证据适用范围可核验；正文与权限撤销无旁路；D7 uncertain 没有盲目重发；真实任务测量报告给出有限参数；全量回归及实际依赖验证有记录。

尚未完成的包、依赖不可用和拒绝诊断的场景必须显式交付状态。不能仅凭单元测试、文档中的图或一个长任务成功宣称整个安全能力完成。

## Open Decisions

架构不再待裁决。实现者需补齐实际 provider/账户与接收方配置、允许测试输入和已审查 profile、实验预算及量测阈值。没有这些权限事实时可以推进离线实现与合成测试，不能对真实敏感数据或新接收方做自主授权。
