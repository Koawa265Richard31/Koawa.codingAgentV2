# 测试证据层验收规则（可迁移规则 v1）

日期：2026-10-06。来源：8 周社区贡献计划第 7 周映射项（用户 2026-10-06 口述定稿），
经 AgentDojo 首题实证（issue #218，含三臂与 2×2 实验）与 KoawaAgent R3 修复双重验证。

## 规则

> **凡是从意图层（提议/trace 记录）判分的检查，必须消费执行层证据；回执不可信（可谎报）时，勘验必须落在环境——事后状态对比。**

## 拆解

| 断言类型 | 合法证据 | 不合法证据 |
| --- | --- | --- |
| "X 发生了" | 执行层证据（执行结果、副作用）；或意图层证据 + 环境勘验互证 | 仅 trace 中存在调用提议 |
| "X 没有发生/没有泄漏" | **先证明检查路径真实执行并命中**，再做否定断言 | 路径未执行时输出为空（平凡真） |
| "执行成功了" | 回执 + 环境效果一致；两者冲突以环境为准 | 仅回执 `error=None`（回执是证词不是勘验） |

## 在本仓库的既有实例

- `tests/test_recall_history_tool.py::test_hit_text_never_reaches_provider_request`：
  先断言检索真实发生且命中（stub 收到查询、回执非错、命中目标 turn），再做"无泄漏"否定断言——本规则的第一实例（R3 修复）。
- D7 执行账本：尝试调用 / 已执行 / uncertain 的状态分离是规则的存储面。
- 计划 B 交付链的 digest 互验（源回执/投影载荷/交付内容三摘要分立）是"回执不可信"约束的工程化。

## 适用方式

新写或评审任何"从记录判分"的测试/评测/检查时按上表核对证据层；违反者视为防空转缺失，
与"不靠放宽断言取绿"同级。不强制立即改造历史测试；新切片起执行。

## 边界

规则的验证范围：两套独立系统（KoawaAgent 自测、AgentDojo 判定链）的确定性实验；
未覆盖真实模型行为差异与并发竞态下的证据层问题——遇到再扩展。
