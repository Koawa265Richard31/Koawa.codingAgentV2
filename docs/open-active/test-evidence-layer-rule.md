# 测试证据层验收规则（可迁移规则 v1.1）

日期：2026-10-06 v1（用户口述定稿）。2026-10-11 v1.1 增补两条
（溯源：AgentScope #2488 review 深读与 #3208 撰写过程中的双检实践；
用户裁决"内容太自洽，信息不全时不敢轻信"后要求落盘）。

## 规则

> **凡是从意图层（提议/trace 记录）判分的检查，必须消费执行层证据；回执不可信（可谎报）时，勘验必须落在环境——事后状态对比。**

## 拆解

| 断言类型 | 合法证据 | 不合法证据 |
| --- | --- | --- |
| "X 发生了" | 执行层证据（执行结果、副作用）；或意图层证据 + 环境勘验互证 | 仅 trace 中存在调用提议 |
| "X 没有发生/没有泄漏" | **先证明检查路径真实执行并命中**，再做否定断言 | 路径未执行时输出为空（平凡真） |
| "执行成功了" | 回执 + 环境效果一致；两者冲突以环境为准 | 仅回执 `error=None`（回执是证词不是勘验） |

## 在本仓库的既有实例

- `tests/test_recall_history_tool.py::test_hit_text_never_reaches_provider_request`：
  先断言检索真实发生且命中（stub 收到查询、回执非错、命中目标 turn），再做"无泄漏"否定断言——本规则的第一实例（R3 修复）。
- D7 执行账本：尝试调用 / 已执行 / uncertain 的状态分离是规则的存储面。
- 计划 B 交付链的 digest 互验（源回执/投影载荷/交付内容三摘要分立）是"回执不可信"约束的工程化。

## 适用方式

新写或评审任何"从记录判分"的测试/评测/检查时按上表核对证据层；违反者视为防空转缺失，
与"不靠放宽断言取绿"同级。不强制立即改造历史测试；新切片起执行。

## 边界

规则的验证范围：两套独立系统（KoawaAgent 自测、AgentDojo 判定链）的确定性实验；
未覆盖真实模型行为差异与并发竞态下的证据层问题——遇到再扩展。

## v1.1 补充（2026-10-11，双检实践沉淀）

### 补充一：痕迹 ≠ 可观测性

**背景**：评估"沙箱静默失效是否有安全含义"时的初版断言（"不留痕迹"）被用户以
常识否决——AgentScope 有服务端账本、应用日志、Redis 持久化，痕迹是存在的。
修正后的准确表述：

> **日志存在 ≠ 事件可检测。** 可观测性 = 痕迹 + 语义分类（正常/异常可区分）+
> 消费通道（告警/SIEM 可达）。三层缺一，安全检测即为零。

实例：AgentScope 的租约过期重建有 logger.warning，但该记录与普通网络重试
不可区分、无事件类型语义、无告警通道——"痕迹在，检测为零"。要检测"沙箱死亡
是否异常"（频率/时机/伴随事件），需要的是带语义的生命周期事件，不是更多日志。

**规则化表述**：评估任何系统的可观测性时，禁止以"有日志"作为"可检测"的证据；
必须分别核验语义分类与消费通道两层。

### 补充二：自洽性警告（双检互捕原则）

**背景**：AI 生成的技术结论具有高自洽性——语言流畅、逻辑自洽、局部无懈可击，
但可能与事实脱钩（实例：三次被用户拦截的过度设计——重复提案、越界 review、
强行缝合；以及"不留痕迹"这类与常识相悖的流畅断言）。

**规则化表述**：

1. **AI 产出不可因自洽而免检**——自洽只证明生成质量，不证明与事实一致；
   验证 AI 输出必须使用外部视角（用户常识核验 / 交叉信源 / 独立复现），
   不能用生成它的同一套推理自证；
2. **用户对信息掌握不全时，"不敢轻信"是正确姿态而非协作摩擦**——此时应
   要求 AI 补全证据链或降级主张，而非要求用户先信任再验证；
3. **双检互捕**：AI 会犯"流畅的错误"（越界、缝合、过度声明），人会犯"信息
   不全的漏判"（错过 bot 时限、不知依赖分组、不知端口占用）——双方独立核验
   的交集才是可信区。**任何一方单独签字的结论都是待验证状态。**

## 边界（v1.1 修订）

规则的验证范围：两套独立系统（KoawaAgent 自测、AgentDojo 判定链）+ 一套第三方
框架（AgentScope）的确定性实验与代码级分析；未覆盖真实模型行为差异与并发竞态
下的证据层问题——遇到再扩展。补充一/二的验证案例：各 1 次实况（AgentScope
日志架构 / 四天内三次拦截），样本尚少，持续累积。
